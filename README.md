# Fashion Editorial Homepage

A high-end, editorial-style e-commerce homepage built with React, Vite, and Tailwind CSS. This project features a minimalist design with custom typography, responsive layout, and interactive components.

## Prerequisites

- Node.js (version 16 or higher recommended)
- npm (comes with Node.js)

## Getting Started

Follow these steps to get the project up and running on your local machine.

### 1. Navigate to the project directory

```bash
cd fashion-editorial
```

### 2. Install Dependencies

Install the required packages using npm:

```bash\nnpm install\n```\n\n### 3. Run the Development Server\n\nStart the local development server:\n\n```bash\nnpm run dev\n```\n\nThe application will be available at `http://localhost:5173` (or the port specified in the terminal).\n\n## Building for Production\n\nTo build the application for production deployment:\n\n```bash\nnpm run build\n```\n\nThe build artifacts will be stored in the `dist/` directory.\n\n## Project Structure\n\n- `src/components/`: Contains reusable UI components (Navbar, Hero, ProductGrid, etc.).\n- `src/App.jsx`: The main application layout assembly.\n- `tailwind.config.js`: Custom Tailwind configuration for colors, typography, and spacing.\n- `src/index.css`: Global styles and Tailwind directives.\n\n## Technologies Used\n\n- [React](https://reactjs.org/)\n- [Vite](https://vitejs.dev/)\n- [Tailwind CSS](https://tailwindcss.com/)\n- [Lucide React](https://lucide.dev/) (Icons)\n
